# Student Management REST API

## 1. Nama Aplikasi

Student Management REST API

## 2. Deskripsi Aplikasi

Student Management REST API adalah aplikasi berbasis web untuk mengelola data siswa.

Aplikasi menyediakan fitur CRUD (Create, Read, Update, Delete) melalui REST API dan frontend menggunakan HTML, CSS, dan JavaScript.

Data siswa disimpan menggunakan database MySQL.

## 3. Teknologi yang Digunakan

- Node.js
- Express.js
- MySQL
- HTML
- CSS
- JavaScript
- REST API
- JavaScript Fetch API
- Git
- GitHub
- Postman / Thunder Client
