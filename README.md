# Student Management REST API

## 1. Nama Aplikasi

Student Management REST API

## 2. Deskripsi Aplikasi

Aplikasi web untuk mengelola data siswa menggunakan REST API.
Aplikasi menyediakan fitur untuk melihat, menambahkan, mengubah, dan menghapus data siswa.

Frontend menggunakan HTML, CSS, dan JavaScript dengan `fetch()` untuk berkomunikasi dengan REST API.

## 3. Teknologi yang Digunakan

- Node.js
- Express.js
- MySQL
- HTML
- CSS
- JavaScript
- REST API
- Git
- GitHub
- Postman / Thunder Client
